# INQ IQ + Magpie Media

Simple static website starter.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. In GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**, then Save.
5. Wait a minute or two for the GitHub Pages URL to appear.

The page uses flyer images rendered from the PDFs you supplied.
